## How to act on this

Retire/merge in `E:\Projects\GridDown-Library` (the spec says never delete an id — mark it retired so bookmarks and flows keep resolving), run `npm run validate`, `npm run build`, then `.\scripts\sync-to-app.ps1 -AppPath E:\Projects\GridDown-main -Apply`. The sync never deletes, so a retired guide also needs removing from the app registry by the build (ask for a `retired` flag in build.mjs if the library does not have one yet).
